## Project Overview
A professional, responsive website for Urban Threads, a Johannesburg-based streetwear retail store. The site showcases products, tells the brand story, and provides a way for customers to enquire and get in touch.

## Website Goals and Objectives
- Showcase products with high-quality imagery
- Generate online sales and enquiries
- Build brand awareness and credibility
- Provide a seamless user experience across all devices

## Key Features and Functionality
- 5-page responsive website (Home, About, Products, Enquiry, Contact)
- External CSS stylesheet (css/style.css)
- Google Fonts (Montserrat + Open Sans)
- CSS Grid and Flexbox layouts
- Responsive design with media queries (tablet + mobile)
- Interactive hover and focus states
- Enquiry form with input styling
